# Portfolio — Muhamad Albarr Khairan

Personal portfolio website of Muhamad Albarr Khairan, Financial Analyst.
Bilingual (English / Bahasa Indonesia), with light and dark mode.

## Structure

```
├── index.html      # Main page
├── css/
│   └── style.css   # All styles
├── js/
│   └── app.js      # React app (content, language toggle, sections)
├── assets/
│   └── photo.webp  # Profile photo
└── README.md
```

## Run locally

Open `index.html` in a browser. An internet connection is needed to load React and Google Fonts from CDN.

## Deploy (GitHub Pages)

Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Edit content

Text (experience, skills, education, etc.) is in `js/app.js`. Colors and layout are in `css/style.css`.
